# PLAY-1003 — Warehouse terminals offline after a firewall rule change

**Severity:** critical
**Resolved:** 2026-04-07
**Systems affected:** terminal-gateway, inventory-sync

## Timeline

- 2026-04-06 05:48 UTC — every handheld terminal in two warehouses fails to
  authenticate. Picking stops.
- 2026-04-06 06:20 UTC — a firewall change applied overnight is found to have
  replaced an allow rule for the terminal subnet with one for a decommissioned
  range.
- 2026-04-06 07:05 UTC — the rule is restored and terminals reconnect.
- 2026-04-07 — the change process is updated and the incident is closed.

## Root cause

A firewall change written against a stale network inventory replaced the allow
rule for the active terminal subnet with a rule for a range that had been
decommissioned six months earlier, so every terminal authentication request was
dropped at the perimeter.

## Impact

Picking stopped for 77 minutes across two warehouses. The delayed shipments were
credited at a recorded loss of CHF 61'250.

## Follow-up

- Fail a firewall change whose subnets are not in the live inventory.
- Page on terminal authentication failure rate, not only on gateway health.
